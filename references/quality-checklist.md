# 无障碍与设计 QA 走查清单

设计评审、上线前打磨、实现验收时使用。逐项检查，未达标项给出具体修复数值。

## 1. 无障碍（WCAG AA 底线）

### 色彩对比
- [ ] 正文文本对比度 ≥ 4.5:1
- [ ] 大文本（≥18pt 或 14pt 粗体）对比度 ≥ 3:1
- [ ] 非文本关键元素（图标/边框/焦点指示）对比度 ≥ 3:1
- [ ] 信息不仅依赖颜色传达（辅以图标/文字/形状）

### 键盘与焦点
- [ ] 全功能可键盘操作，无键盘陷阱
- [ ] 焦点指示清晰可见（outline ≥ 2px，对比度 ≥ 3:1）
- [ ] Tab 顺序符合视觉与逻辑顺序
- [ ] 弹窗打开后焦点进入弹窗，关闭后回到触发元素

### 屏幕阅读器
- [ ] 语义化 HTML（button/nav/main 等原生标签优先）
- [ ] 图标按钮有 aria-label，纯装饰元素 aria-hidden
- [ ] 表单控件关联 label，错误提示用 aria-describedby

### 包容性
- [ ] 触控目标 ≥ 44×44px，间距足够防误触
- [ ] 尊重 prefers-reduced-motion（提供减动效版本）
- [ ] 浏览器文字放大 200% 布局不破
- [ ] 错误预防：清晰标签、输入说明、提交前确认破坏性操作

## 2. 设计一致性 QA

- [ ] 所有颜色/字号/间距/阴影来自 Token，无流浪数值
- [ ] 同类组件圆角、阴影、间距全站统一
- [ ] 组件状态完备：default/hover/active/focus/disabled + loading/error/empty
- [ ] 图标风格统一（线性/面性、线宽一致）
- [ ] 文案风格统一（术语、语气、大小写规则）

## 3. 响应式走查

- [ ] 320px 最窄断点无横向滚动
- [ ] 640/768/1024/1280px 各断点布局无破版
- [ ] 文本溢出处理（截断/换行）在极端长度下正常
- [ ] 移动端无关键功能被隐藏

## 4. 性能与实现

- [ ] 图片素材已压缩并多倍图导出（1x/2x/3x 或 WebP/AVIF）
- [ ] 图标用 SVG 且已精简
- [ ] 动效只动画 transform/opacity，不触发布局重排
- [ ] 加载态与骨架屏已定义
- [ ] 开发标注精确到 px/rem，开发者可独立实现

## 5. 成功指标（验收线）

| 指标 | 达标线 |
|------|--------|
| 设计系统一致性 | ≥ 95% 界面元素复用 Token 与组件 |
| 无障碍 | 全部满足 WCAG AA（对比度 ≥ 4.5:1） |
| 开发交付准确率 | ≥ 90% 实现一次到位，无需设计返工 |
| 组件复用 | 组件有效复用，无重复造轮子产生设计债 |
| 响应式 | 全部目标断点无破版 |

## 走查输出格式

```

### 通过项：X/Y
### 未达标项

|---|------|------|------|----------------------|--------|
| 1 | 对比度 | 次要文本 3.8:1 不达标 | 卡片描述 | #6b7280 → #4b5563（达 4.6:1） | P0 |

### 结论：[可上线 / 修复 P0 后上线 / 需重新设计]
```
